# simple-pwd-generator

A universal App for Mac/iPad/iPhone that generates passwords. Not trusting randomness from the generator, some things that seem un-streamlined are used to add factors of randomness. 

## Password types
Password types are random-character or English and non-accented Spanish word/multi-word/phrase. You can use separators in either type of password. (Check the settings options for language choices)


## Languages

Will allow for multiple dictionaries (and user-provided dictionaries). Currently supports English by default and can add Spanish (non-accented).
